# DOHNUT AI Operating System Roadmap

## Recommended Sequence

1. **Brand Truth** — lock identity, logo, colours, typography, voice and non-negotiables.
2. **Controlled Vocabulary** — maintain the glossary and naming rules.
3. **Creative Modules** — finalize DOH Language, DOH Cinema, Doh Boy and Pop Culture Playbook.
4. **Creative Genome** — formalize structured briefs.
5. **Prompt Registry** — version prompts and examples.
6. **Prompt Compiler** — generate target-provider prompts.
7. **Visual QA** — enforce taste, tactile quality and recognition.
8. **Asset Registry** — record approved outputs and metadata.
9. **Performance Loop** — connect campaign results back to Creative Memory.

## Quality Checklist

### Documentation

- [ ] YAML front matter complete.
- [ ] Semantic version present.
- [ ] H1/H2/H3/H4 hierarchy valid.
- [ ] Tables and code blocks are consistent.
- [ ] Cross-references resolve.
- [ ] Glossary terminology is consistent.
- [ ] CHANGELOG updated.

### Creative

- [ ] Brand Truth respected.
- [ ] DOH voice recognizable.
- [ ] Product remains central.
- [ ] Cultural reference is relevant.
- [ ] Output is memorable without being confusing.

### Visual

- [ ] Can I Taste It?
- [ ] Can I Feel It?
- [ ] Can I Recognize It?
- [ ] Logo is not distorted.
- [ ] No unnecessary imitation of third-party protected assets.

## Change Management

Any change to a core term, identity rule, character canon, prompt contract or schema requires a version review and cross-reference audit.
