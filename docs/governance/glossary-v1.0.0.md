# DOHNUT Controlled Glossary

## Terms

| Term | Definition |
|---|---|
| **DOHNUT** | Master brand for the Malaysian premium donut D2C system. |
| **DOH Language™** | Verbal identity system based on DOH wordplay. |
| **DOH Cinema™** | Cinematic storytelling and transformed pop-culture title framework. |
| **Doh Boy™** | DOHNUT secondary character and internet-native personality. |
| **Pop Culture Playbook™** | Library and operating rules for culture-aware campaigns and content. |
| **Visual AI Engine™** | System that converts structured creative briefs into production-ready visual prompts and QA workflows. |
| **Creative Genome** | Structured representation of creative intent and variables. |
| **Prompt Compiler** | Logic that combines genome, brand rules and modules into a generation prompt. |
| **Brand Truth** | Non-negotiable facts, identity and rules defining DOHNUT. |
| **Visual QA** | Quality assurance against product, brand and creative requirements. |
| **Creative Memory** | Approved learnings, assets and performance feedback retained for future work. |
| **D2C** | Direct-to-consumer operating model. |
| **Production Prompt** | Prompt ready for use by a target AI generation system. |

## Naming Rules

Use the exact forms **DOHNUT**, **DOH Language™**, **DOH Cinema™**, **Doh Boy™**, **Pop Culture Playbook™**, **Visual AI Engine™**, and **Creative Genome** unless a formal versioned change is approved.
