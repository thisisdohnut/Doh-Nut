# DOHNUT AI Operating System

## Tujuan

Dokumentasi ini menyatukan **Brand Truth**, **DOH Language™**, **DOH Cinema™**, **Doh Boy™**, **DOHNUT Pop Culture Playbook™**, dan **DOHNUT Visual AI Engine™** ke dalam satu sistem operasi kreatif yang boleh dikembangkan secara berperingkat.

## Brand Core

| Field | Standard |
|---|---|
| Brand | DOHNUT / Doh-Nut |
| Company | GangNiaga Sdn. Bhd. |
| Market | Malaysia |
| Primary geography | KL / Selangor / Klang Valley |
| Model | D2C, online-first, delivery-led |
| Product | Premium donuts: classic, sprinkled, stuffed, specialty |
| Tagline | **GOOD VIBE. GOOD DOH.** |
| Creative DNA | Playful, bold, tactile, premium, authentic |
| Creative language | **DOH** |

## System Architecture

```text
BRAND TRUTH
    ↓
CREATIVE GENOME
    ↓
DOH LANGUAGE™ ── DOH CINEMA™ ── DOH BOY™
    ↓
POP CULTURE ADAPTER
    ↓
PROMPT COMPILER
    ↓
GOOGLE FLOW / IMAGE / VIDEO AI
    ↓
VISUAL QA
    ↓
ASSET REGISTRY
    ↓
PERFORMANCE + CREATIVE MEMORY
```

## Implementation Order

1. Lock Brand Truth and controlled glossary.
2. Finalize creative modules and naming rules.
3. Register prompts and skills.
4. Implement Creative Genome schema.
5. Build prompt compiler.
6. Connect visual generation workflows.
7. Add QA and governance gates.
8. Record approved assets and performance feedback.

## Quality Gate

Setiap dokumen atau asset baharu perlu menjawab:

- Adakah ia konsisten dengan Brand Truth?
- Adakah ia menggunakan istilah terkawal?
- Adakah versi dokumen jelas?
- Adakah cross-reference dikemas kini?
- Untuk visual: **Can I Taste It? Can I Feel It? Can I Recognize It?**
- Untuk parody: adakah rujukan cukup transformatif dan tidak mengelirukan sebagai official association?

## Status

Foundation v1.0.0. Dokumen ini ialah baseline dan perlu dikemas kini apabila Brand Guidelines, Pop Culture Playbook, Visual AI Engine atau prompt/skills registry berubah.
