# DOHNUT Pop Culture Playbook™

## Purpose

Library dan operating rules untuk menghasilkan culture-aware content yang boleh bergerak antara product, entertainment, Malaysian references dan internet behaviour.

## Content Pillars

1. **DOH Language** — short-form verbal jokes.
2. **DOH Cinema** — genre and movie-title transformations.
3. **Doh Boy** — recurring character content.
4. **Malaysian Culture** — local expressions, moments and references.
5. **Product Theatre** — product-first visual stories.
6. **Community** — UGC, reactions and comments.
7. **Seasonal** — Ramadan/Raya, Merdeka, CNY, Deepavali, birthdays and other relevant moments.
