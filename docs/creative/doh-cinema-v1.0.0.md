# DOH Cinema™

## Definition

**DOH Cinema™** ialah campaign storytelling framework yang menggunakan genre, cinematic composition dan transformed wordplay untuk menjadikan produk sebahagian daripada cerita.

## Title System

Contoh working titles:

- **DOH WICK** — action
- **DOH NUT IMPOSSIBLE** — spy/action
- **DOH & FURIOUS** — racing
- **BACK TO THE DOH** — time travel
- **THE LAST DOH** — drama
- **500 DAYS OF DOH** — romance
- **DOH NUT SCREAM** — horror/comedy
- **DOH OF THE APES** — adventure

## Campaign Formula

```text
PRODUCT
  +
DOH PUN
  +
GENRE
  +
CHARACTER
  +
VISUAL WORLD
  +
CTA
  =
DOH CINEMA CAMPAIGN
```

## Creative Guardrails

- Treat titles as parody-inspired creative devices, not claims of affiliation.
- Prefer transformed, humorous expressions rather than reproducing protected artwork, characters, dialogue or logos.
- Keep the donut/product central.
- Add a clear DOHNUT brand signature.

## Output Formats

- Poster
- Hero image
- Short video
- Trailer-style social post
- Product drop
- Billboard
- Packaging sleeve
