# Doh Boy™

## Role

**Doh Boy™** ialah secondary character dan internet-native personality untuk DOHNUT. Dia membantu menterjemah brand personality kepada behaviour, reactions, memes dan recurring content.

## Personality

- Cheeky
- Curious
- Playful
- Bold
- Rebellious
- Funny
- Social
- Opinionated
- Reactive
- Meme-able

## Voice

Pendek, direct, conversational dan confident. Gunakan DOH Language apabila ia meningkatkan punchline.

## Behaviour Modes

| Mode | Behaviour |
|---|---|
| Hype | Celebrates product drops |
| Chaos | Creates playful trouble |
| Reviewer | Gives exaggerated reactions |
| Host | Introduces campaigns |
| Commenter | Replies to social comments |
| Action Hero | Supports DOH Cinema stories |
| Local Boy | Uses Malaysian cadence naturally |

## Canon Rules

- Doh Boy bukan donut semata-mata; dia ialah character dengan personality.
- Jangan mengubah identiti character tanpa canonical update.
- Elakkan gesture, costume atau visual yang terlalu menyerupai mascot pihak lain.
- Character mesti kekal brand-safe dan inclusive.
